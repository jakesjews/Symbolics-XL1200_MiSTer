# Keyboard

Letters, digits, punctuation, Shift, Control, Tab, Return and Space are where
you expect. The Symbolics-only keys are on these PC keys:

- F1 Select, F2 Network, F3 Function, F4 Suspend, F5 Resume, F6 Abort
- F7 Clear Input, F8 Complete, F9 Help, F10 Line, F11 Page
- Esc Escape
- Backspace and Delete: Rubout
- Home Refresh, End and keypad Enter: End
- Page Up Square, Page Down Scroll, Print Screen Triangle
- `[` and `]`: the Symbolics `(` and `)` keys
- Insert: `|`
- Left Alt Meta, Right Alt Symbol, Num Lock Symbol
- Windows keys Super, Menu key Hyper
- Caps Lock Caps Lock, Scroll Lock Mode Lock
- Pause/Break switches the picture between the console and the color screen;
  Genera never sees it. The core's Display option picks the one shown first.

The mouse's three buttons are the Symbolics mouse's Left, Middle and Right.
